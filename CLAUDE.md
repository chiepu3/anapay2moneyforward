### Configuration Requirements
Before running the script, ensure `.env` file contains:
```
EMAIL="your_moneyforward_email"
PASSWORD="your_moneyforward_password" 
SHEET_ID="your_google_spreadsheet_id"
DEBIT_CARD_ASSET_NAME="your_debit_card_asset_name"  # Optional
```

The script also requires `credentials.json` (Google OAuth credentials) and `token.json` (generated by quickstart.py).

## Architecture Overview

This is a Python automation script that extracts transaction data from Gmail and registers it with Money Forward ME via web automation.

### Core Components

**Main Script (`anapay2mf.py`)**
- Primary entry point with `main()` function
- Orchestrates the entire workflow: Gmail → Spreadsheet → Money Forward

**Data Flow:**
1. **Gmail Extraction** (`get_transaction_emails()`) - Fetches ANA Pay and debit card notification emails
2. **Email Parsing** (`get_mail_info()`, `get_debit_card_mail_info()`) - Extracts transaction details
3. **Spreadsheet Storage** (`gmail2spredsheet()`) - Writes to Google Sheets as intermediate storage
4. **Money Forward Registration** (`spreadsheet2mf()`) - Automates web form submission

**Authentication (`quickstart.py`)**
- Handles Google API OAuth flow for Gmail and Sheets access
- Creates/refreshes `token.json` credentials

**Web Automation (`login_mf()`, `add_mf_record()`)**
- Uses Helium library for browser automation
- Handles Money Forward ME login including 2FA
- Submits transaction records via web forms

### Key Data Structures

**`ANAPay` dataclass** - Unified transaction record containing:
- `email_date`: When notification email was received
- `date_of_use`: Actual transaction date/time  
- `amount`: Transaction amount (int)
- `store`: Merchant name
- `transaction_type`: "ANAPay" or "DebitCard"
- `asset_name`: Payment method identifier in Money Forward

### External Dependencies

**Google APIs:**
- Gmail API for email access
- Google Sheets API for data storage
- OAuth2 authentication flow

**Web Automation:**
- Helium library for Firefox-based automation
- Targets Money Forward ME web interface

**Google Spreadsheet Structure:**
- `ANAPay` sheet: Main transaction log with columns `email_date | date_of_use | amount | store | transaction_type | asset_name | mf`
- `ANAPayStore` sheet: Optional store categorization mapping

### Email Parsing Specifications

**ANA Pay emails:** from `payinfo@121.ana.co.jp` with format:
```
ご利用日時：YYYY-MM-DD HH:MM:SS
ご利用金額：N,NNN円  
ご利用店舗：STORE_NAME
```

**Debit Card emails:** from `post_master@netbk.co.jp` with expected format:
```
利用日時   ： YYYY/MM/DD HH:MM:SS
利用加盟店 ： STORE_NAME
引落金額   ： N,NNN.NN
```
